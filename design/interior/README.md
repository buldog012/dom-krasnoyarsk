## 3D-визуализация в Blender

Папка [blender/](blender/): дом собирается скриптом по тем же данным, что на странице, поэтому стены, окна, двери и мебель совпадают с чертежами.

| Файл | Что делает |
|---|---|
| `export_data.js` | вынимает из `index.html` комнаты, стены, четыре схемы мебели и семь стилей в `house.json` (запуск: `node export_data.js`) |
| `build_house.py` | строит дом в Blender 5.2: полы из досок и плитки, стены с проёмами и наличниками, двери, окна, мебель с подушками, фасадами и ножками, светильники по стилю, шторы, картины, растения, террасу с перилами «крестом»; свет от солнца и неба через окна; рендерит Cycles на процессоре |
| `render_all.sh` | пакет: схема А в 7 стилях (план, дом без крыши, кухня-зал, кухня, спальня, терраса), схемы Б, В, Г в 7 стилях (план, дом без крыши, кухня-зал). Готовые кадры пропускает |
| `export_desktop.py` | раскладывает готовые кадры в папку на рабочем столе по стилям с русскими именами |
| `renders/` | кадры `{схема}-{стиль}-{вид}.jpg`: схема a/b/v/g, вид plan, axo, kh, kitchen, bed3, terrace |

Один кадр на этом ноутбуке (Ryzen 5 5600H, 12 потоков, без видеокарты для Cycles): план около 1,5 минуты, интерьер около 3 минут. Весь пакет из 105 кадров (схема А: 7 стилей × 6 видов, схемы Б, В, Г: 21 сочетание × 3 вида) идёт около трёх с половиной часов.

Один кадр вручную:

```
blender -b --factory-startup --python build_house.py -- --layout 0 --style loft --views kh,axo --out renders --samples 64 --res 1440x960
```

Если в `index.html` поменялась мебель: `node export_data.js`, удалить устаревшие кадры из `renders/`, запустить `bash render_all.sh`.

Альбом для печати: [print-3d.html](print-3d.html) → `album-3d.pdf`, одиннадцать листов A3 (собирается той же командой Chrome, что и чертежи).

## Для покупателя

Презентация интерьеров, которую можно отправить покупателю в мессенджере. Две страницы на тех же рендерах Blender:

- [buyer.html](buyer.html): семь кадров 1600 × 1200 (обложка, планировка с площадями по паспорту, четыре схемы, семь стилей кухни-гостиной и терраса, спальня и кухня, контакты). На каждом кадре подпись, что это 3D-визуализация, не фотографии.
- [buyer-one.html](buyer-one.html): всё то же одним длинным листом 1600 × 2443, если нужна одна картинка.

Готовые файлы в `buyer/`: `slide-1.jpg` … `slide-7.jpg`, `one-sheet.jpg`, `buyer.pdf` (семь страниц, 3,5 МБ, не в git). Копия с русскими именами на рабочем столе: «Планировки дома в Зыково\Для покупателя».

Тексты только из фактов сайта (готов под чистовую отделку, семейная ипотека, адрес, телефон) и из данных мебели на странице интерьера. Цены нет намеренно: она меняется, её называет владелец.

Пересобрать после правок: локальный сервер из папки проекта (`python -m http.server 8765 --bind 127.0.0.1`), снимок всей страницы при ширине окна 1600 (Playwright, `fullPage`), нарезка снимка на кадры по 1200 px и перевод в JPEG скриптом `buyer/slice.ps1` (`-In снимок.png -OutDir buyer -SlideH 1200`; для одного листа `-SlideH 100000`). PDF той же командой Chrome, что и чертежи, с адресом `design/interior/buyer.html`; фон печатается благодаря `print-color-adjust: exact`.

## Картинки

- `viz/*.jpg`: кадры из 3D-модели, по три в ряд (2400 × 600). Семь файлов по стилям (кухня-зал, спальня, терраса, расстановка А) и три по расстановкам `layout-a/b/c` (кухня-зал, кухня, вторая спальня, стиль Северный свет). Точны по планировке, упрощены по форме мебели. Снимаются режимом `window.__viz` на странице.
- `renders/*.jpg`: ИИ-картинки по текстовому описанию стиля (сервис pollinations.ai, бесплатный, без ключа). Качество среднее, окна и пропорции не повторяют дом. Бесплатный доступ ограничен частотой: пакет из 21 картинки добирался с паузами, не все могли дойти. Промпты для платных генераторов на странице.

Ни те, ни другие не фотографии дома: на сайт и в объявления не ставить.

## Как получить точные фотореалистичные рендеры

По уроку 5: Nano Banana для картинки, Higgsfield или Kie для видео. Промпт берётся со страницы (он включает выбранную расстановку и палитру), к нему прикладывается реальное фото комнаты из `v2/img/` или кадр из `viz/`. Перед платной генерацией показать стоимость и договориться о числе попыток.
