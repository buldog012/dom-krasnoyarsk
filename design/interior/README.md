## Семь стилей по две палитры

Северный свет (скандинавский), Тёплый минимализм (джапанди), Графит и дерево, Мягкий греж (современная классика), Барокко, Лофт, Мид-сенчури. У каждого палитра по девяти ролям в hex, материалы под сметчика, описание по комнатам. Барокко и греж включают молдинги и карниз в 3D, барокко люстру, лофт кирпичную акцентную стену и бетонный пол.

## Картинки

- `viz/*.jpg`: кадры из 3D-модели, по три в ряд (2400 × 600). Семь файлов по стилям (кухня-зал, спальня, терраса, расстановка А) и три по расстановкам `layout-a/b/c` (кухня-зал, кухня, вторая спальня, стиль Северный свет). Точны по планировке, упрощены по форме мебели. Снимаются режимом `window.__viz` на странице.
- `renders/*.jpg`: ИИ-картинки по текстовому описанию стиля (сервис pollinations.ai, бесплатный, без ключа). Качество среднее, окна и пропорции не повторяют дом. Бесплатный доступ ограничен частотой: пакет из 21 картинки добирался с паузами, не все могли дойти. Промпты для платных генераторов на странице.

Ни те, ни другие не фотографии дома: на сайт и в объявления не ставить.

## Что принято, а не измерено

- Толщина наружных стен 250 мм, перегородок 150 мм. Потолок 2,7 м.

## Как получить точные фотореалистичные рендеры

По уроку 5: Nano Banana для картинки, Higgsfield или Kie для видео. Промпт берётся со страницы (он включает выбранную расстановку и палитру), к нему прикладывается реальное фото комнаты из `v2/img/` или кадр из `viz/`. Перед платной генерацией показать стоимость и договориться о числе попыток.
