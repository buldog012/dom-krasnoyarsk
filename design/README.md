# Дизайн: карта папки

Прочитай этот файл перед любой работой с внешним видом сайта: новая секция, правка стилей, картинка, письмо или презентация по дому.

| Что | Где | Зачем |
|---|---|---|
| Закон: палитра, шрифты, геометрия, компоненты, анимации, раздел ЗАПРЕЩЕНО | [design-system.md](design-system.md) | Единственные правила оформления. Значения живут в `v2/style.css`, блок `:root` |
| Референсы и разбор лучших сайтов ниши | [refs/analysis.md](refs/analysis.md) | Откуда взяты приёмы, что не брать |
| Бриф главной: кто смотрит, что должен понять, структура секций | [brief-main.md](brief-main.md) | Порядок и смысл секций до оформления |
| Профиль главной: как устроен каждый экран, тексты кнопок, состояния | [profiles/main.md](profiles/main.md) | Чтобы следующую правку делать по профилю, не переспрашивая |
| Три варианта первого экрана и суд | [variants/hero-variants.html](variants/hero-variants.html), [variants/README.md](variants/README.md) | Почему выбран вариант А |
| Проверка экрана на трёх ширинах | [check-main.md](check-main.md) | Что проверено, что осталось |
| Живая страница | `../v2/index.html`, `../v2/style.css`, `../v2/script.js`, фото в `../v2/img/` | Код |

Порядок работы над любым экраном: бриф (структура без оформления) → варианты композиции → выбор → вёрстка по дизайн-системе → проверка в браузере на 375 / 768 / 1440 → запись в профиль.

Правка владельца «не так» сначала записывается в раздел «Выучено на правках» в `design-system.md` (или в профиль экрана), потом меняется код.
